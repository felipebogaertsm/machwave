# Models

Domain model layer representing the physical components of a rocket propulsion system. This is where you define your motor, propellant, grain geometry, thrust chamber, and feed system.

Submodules:

- [motors](models/motors.md) — `SolidMotor` and `BiliquidEngine` definitions
- [propellants](models/propellants.md) — Propellant components, formulations, and thermochemical properties
- [grain](models/grain.md) — Grain geometry and burn regression models
- [thrust_chamber](models/thrust_chamber.md) — Nozzle, combustion chamber, and injector
- [feed_systems](models/feed_systems.md) — Feed system models for biliquid engines
