# core.structural

Structural analysis utilities for motor hardware sizing and verification.

- **Pressure vessels** — Von Mises equivalent stress for thick-walled cylindrical casings, flat-plate (bulkhead) stress, and burst pressure estimation from yield strength.
- **Bolted joints** — Shear stress per bolt, bearing stress on plates, tear-out shear, and net-section tension stress for flange connections.

Useful for quick checks on casing wall thickness, closure plate sizing, and flange bolt patterns.
