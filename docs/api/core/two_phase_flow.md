# core.two_phase_flow

Orifice mass flux of a propellant that may flash inside the orifice: the homogeneous
equilibrium flux and Dyer's non-homogeneous non-equilibrium blend of it with the
incompressible flux.
The model is explained in [Injector Flow](../../explanations/injector_flow.md).
