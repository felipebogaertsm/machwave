# adapters

Bridges between Machwave's internal ballistics results and external simulation tools. Currently provides a RocketPy adapter that wraps a Machwave motor and its `SimulationResult` into a RocketPy-compatible motor object, enabling 6-DOF trajectory simulation driven by Machwave's ballistic output.

See [adapters.rocketpy](adapters/rocketpy.md) for the RocketPy integration details.

::: machwave.adapters
